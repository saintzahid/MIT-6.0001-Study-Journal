# MIT OCW: 6.0001 - Introduction to Computer Science and Programming in Python

This repository contains my personal notes, exercise solutions, and problem set implementations for the MIT OpenCourseWare (OCW) course **6.0001: Introduction to Computer Science and Programming in Python** (Fall 2016).

The purpose of this repository is to track my self-study progress and showcase my solutions as a personal learning portfolio.
